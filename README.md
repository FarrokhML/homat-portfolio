# نمونه‌کارهای هومات

هر پوشه یک تحلیلِ اجراشده است: خط لوله‌ی کامل، گزارش با عددهای
واقعیِ همان اجرا، و نمودارها. داده‌ی خام این‌جا نیست — با DVC
نسخه‌بندی شده و لینک منبعش در گزارش هر پروژه هست.

بازتولید:

```
pip install -r requirements.txt
python pipeline.py
```
